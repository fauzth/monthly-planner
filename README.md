# Monthly Planner

Aplikasi web mobile-first untuk merencanakan gaji bulanan dengan sistem pocket.

## Fitur
- Total saldo dan pemasukan
- Pocket dinamis (buat, edit, arsip)
- Catat pemasukan, pengeluaran, dan transfer antar pocket
- Saldo pocket otomatis berkurang dari pengeluaran
- History dengan filter bulan dan pocket

## Tech Stack
React (Vite), JavaScript, Tailwind CSS, React Router, Supabase (rencana)

## Menjalankan
npm install 
npm run dev
